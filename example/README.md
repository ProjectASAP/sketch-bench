# Examples

## Overview

To provide a straightforward view about what the executable of main branch can do, examples of command line execution/scripts and corresponding outputs are dumped into files under this directory.

Everything under it is generated by [`regenerate.sh`](regenerate.sh).

```bash
./example/regenerate.sh
```

## Directory Structure

```
CMS/  CS/  HLL/  KLL/
└── insert-and-query/   two operations, both metrics, cpu and memory along for the ride
    query-accuracy/     one operation, scored against ground truth
    merge/              one operation, read as a time and as a rate
        ├── command.sh     the two commands, differing only by `--flat`
        ├── records.jsonl  one record per square
        └── flat.json      the same squares as one row
```

Every example runs `--impl lib`, which is `asap_sketchlib`.

All four use one workload, 200000 items drawn from 20000 keys at Zipf 1.1.
